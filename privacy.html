Politique de confidentialité – Rust Learn

Dernière mise à jour : 7 octobre 2026

Données collectées

Rust Learn ne crée pas de compte et ne contient aucun outil d'analyse. L'application elle-même ne collecte aucune donnée personnelle ; les seules données qui quittent l'appareil sont décrites ci-dessous (publicités, achats, compilation du code). Votre progression (leçons, notes, série, réglages, prénom saisi à l'accueil) est stockée uniquement sur votre appareil. Elle peut être incluse dans la sauvegarde Android de votre compte Google si vous l'avez activée.

Publicités

La version gratuite affiche des publicités fournies par Google AdMob (Google Ireland Limited). Pour les afficher et mesurer leurs performances, le SDK Google Mobile Ads peut collecter l'identifiant publicitaire de l'appareil, l'adresse IP, des informations sur l'appareil et des interactions avec les publicités, et utiliser des cookies ou identifiants similaires. Dans l'Espace économique européen, au Royaume-Uni et en Suisse, votre consentement est demandé au premier lancement (plateforme de gestion du consentement de Google) ; sans consentement, seules des publicités non personnalisées peuvent être affichées. Vous pouvez modifier votre choix à tout moment dans Réglages > À propos > « Choix de confidentialité publicitaire ». Voir comment Google utilise les données et les règles de confidentialité de Google. Aucune publicité n'est affichée après l'achat « à vie » ou pendant l'abonnement Pro, ni pendant un exercice.

Achats et abonnement

L'achat « à vie » et l'abonnement Pro sont traités par Google Play. Rust Learn ne reçoit ni vos coordonnées de paiement ni votre identité : l'app interroge seulement Google Play pour savoir quels produits sont actifs sur votre compte, et garde ce statut sur l'appareil pour fonctionner hors connexion. L'abonnement se gère et se résilie depuis Google Play.

Compilation du code

Quand vous exécutez un exercice de code ou le bac à sable, le code Rust que vous avez écrit est envoyé au Rust Playground (play.rust-lang.org), un service tiers géré par la communauté Rust, qui le compile et renvoie le résultat. Aucune autre information n'est envoyée. N'écrivez pas de données personnelles dans votre code.

Rapports de plantage

Si l'application plante, la trace technique de l'erreur est enregistrée dans un fichier local sur votre appareil. Elle n'est jamais envoyée automatiquement : au lancement suivant, l'app vous propose de l'envoyer par e-mail, avec la version de l'app, la version d'Android et le modèle de l'appareil. Vous voyez le message dans votre application de messagerie et choisissez de l'envoyer ou non. Le fichier est supprimé dès que vous avez fait votre choix.

Notifications

Les rappels quotidiens sont programmés localement sur l'appareil. Vous pouvez les désactiver dans les réglages de l'app.
